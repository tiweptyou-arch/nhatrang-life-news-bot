# Нячанг Лайф | Новости — бот

Telegram-бот для отбора и подготовки русскоязычных локальных новостей Нячанга и провинции Кханьхоа, регулярного прогноза погоды и управления рекламой.

## Что умеет

- Проверяет RSS-источники, дату публикации и метаданные статьи; отсеивает старые, повторные и малополезные материалы.
- Формирует короткий русский пересказ с отдельным жирным заголовком.
- Ищет подходящее фото; не публикует текстом, если изображение недоступно.
- Отправляет личный предпросмотр редактору с кнопками публикации, правки заголовка/текста/фото, переноса таймера и отклонения.
- Ставит обычные материалы на 15-минутный таймер; только ограниченный класс проверенных срочных предупреждений может выйти сразу.
- Готовит прогнозы на 08:00 и 18:00 по времени Нячанга и отслеживает существенные изменения погоды.
- Ведёт очередь, дедупликацию и рекламные таймеры в приватном Supabase, а не в публичном файле состояния.

## Запуск

Сначала прочитайте [инструкцию по безопасному подключению](DEPLOYMENT.md). Боевой workflow требует приватного хранилища Supabase и GitHub Actions Secrets. Секреты не нужно записывать в репозиторий.

GitHub Actions запускает тесты отдельно от боевого job; pull request не публикует сообщения в Telegram.

# Развёртывание редакционного бота

## 1. Supabase

Текущая схема — одна строка `public.bot_state` с закрытым JSONB состоянием. Выполните `supabase_schema.sql` для нового проекта. Список RSS и их язык/тип хранится в `sources.json`; его можно менять без правки Python-кода. В существующем проекте можно применить `supabase_migrations/20261105_bot_state_security.sql`: миграция включает RLS и повторно ограничивает права, не удаляя строки или поля. Новые `openai_usage`, уровни проверки и журналы генерации добавляются приложением в JSONB; отдельного изменения таблиц не требуется.

## 2. GitHub Secrets и Variables

Откройте **Settings → Secrets and variables → Actions**.

| Secret | Назначение |
|---|---|
| `TELEGRAM_BOT_TOKEN` | Telegram Bot API |
| `ADMIN_USER_ID` или `ADMIN_USER_IDS` | Числовые ID администраторов |
| `SUPABASE_URL` | URL проекта Supabase |
| `SUPABASE_SECRET_KEY` | Серверный ключ Supabase с доступом `service_role` |
| `OPENAI_API_KEY` | Необязательно: платная редакторская модель и изображения |
| `WEATHERAPI_KEY` | Погодные данные в коммерческом режиме |

`TELEGRAM_CHAT_ID` остаётся для совместимости, но публикация разрешена только в отдельном контролируемом GREEN-пути. Не добавляйте ключи в код, логи или коммиты. `GEMINI_API_KEY` больше не используется. Без `OPENAI_API_KEY` работает бесплатный режим: перевод через доступный Google Translate endpoint и локальные иллюстрации Pillow; нужен интернет, доступность перевода не гарантируется.

Создайте Actions **Variable** `AUTO_PUBLISH=false`. После проверки настроек и добавления `OPENAI_API_KEY` можно изменить её на `true`: прямой режим ограничен низкорисковыми материалами GREEN. Без OpenAI-ключа публикация в канал остаётся ручной. Юридические, медицинские, погодные, транспортные, срочные и неопределённые материалы остаются в личной очереди. Без переменной используется `false`.

## 3. Бесплатный режим

Чтобы начать без оплаты OpenAI, просто не задавайте `OPENAI_API_KEY`. Бот переключится на правиловую редактуру и перевод через доступный неаутентифицированный Google Translate web endpoint (без SLA, может ограничиваться или перестать работать), а вместо Image API нарисует оригинальную локальную иллюстрацию и наложит на неё заголовок. Платные расходы OpenAI в этом режиме равны нулю. Для картинок всё равно нужен `Pillow` из `requirements.txt`; Actions устанавливает его автоматически.

Когда будете готовы подключить OpenAI, добавьте `OPENAI_API_KEY` в Actions Secrets.

## 4. Лимиты и стоимость

- Общий предел OpenAI: `$0.75` в день и `$8` в месяц; `$2` остаются резервом относительно пользовательского лимита $10.
- Уведомления администраторам на `$5` и `$7` месячного расхода.
- Изображения: максимум 8 попыток, перед каждой оставляется резерв `$0.15` на возможную генерацию, общий предел `$0.25` в день; месячный лимит изображений `$7`.
- Текст: до 40 редакторских вызовов в день. До запроса проверяется оценочный резерв, после ответа сохраняются реальные токены и стоимость.
- Модель текста: `gpt-6-luna`, стандартная цена на дату проверки `$0.10/1M` входных и `$0.50/1M` выходных токенов.
- Изображения: `gpt-image-2.5-flare`, качество `low`, 1536×864. Плата считается по токенам из ответа API, а не фиксированной ставкой за картинку.

Фактические тарифы меняются; смотрите [модель GPT-6 Luna](https://developers.openai.com/api/docs/models/gpt-6-luna), [прайс OpenAI](https://developers.openai.com/api/docs/pricing) и [Images API](https://developers.openai.com/api/docs/guides/image-generation).

## 5. GitHub Actions и Telegram

Workflow запускается каждые пять минут. Это периодическая задача, а не постоянно работающий сервер. Погодные окна — 07:35 и 19:30 по Нячангу, существенные изменения проверяются примерно раз в час. Telegram-команды и callback-кнопки могут ждать очередного Actions-запуска.

Ручной погодный тест доступен через **Actions → Nha Trang News Bot → Run workflow → preview_weather_now**; он отправляет предпросмотр только настроенному администратору. Не включайте это для публичного канала.

Обычный режим создаёт приватные предпросмотры. При `AUTO_PUBLISH=true` публикация в канал возможна только для GREEN-материала с официальным источником и картинкой. Это не гарантирует, что каждый материал будет опубликован: YELLOW/RED должны оставаться ручными, а отсутствие подходящих новостей означает отсутствие публикации.

## 6. Локальный запуск и диагностика

Скопируйте `.env.example` в `.env`, заполните переменные локально и задайте `BOT_STATE_FILE`. Не коммитьте `.env`. Нужен Python 3.10+ и Pillow из `requirements.txt`.

```bash
python3 -m pip install -r requirements.txt
python3 -m py_compile bot.py imagegen.py
python3 -m unittest discover -s tests -v
```

В Telegram: `/status`, `/weather`, `/sources`, `/budget`, `/test`, `/pause`, `/resume`. `/test` выполняет только локальные проверки доступности функций; он не отправляет тестовые сообщения в канал.

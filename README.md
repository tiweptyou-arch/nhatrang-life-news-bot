# Нячанг Лайф | Новости — редакционный бот

Бот собирает новости и погоду по Нячангу и Вьетнаму, готовит русскоязычные материалы, создаёт иллюстрации и отправляет готовые черновики редактору в личный Telegram.

**Бот не публикует сообщения в публичный канал.** Направление всех методов отправки и редактирования Telegram API ограничено личными чатами администраторов. Редактор публикует пост самостоятельно; кнопка в предпросмотре только отмечает ручную публикацию в истории бота.

## Уже работает

- Поиск материалов через RSS и официальные/местные источники, проверка свежести и дедупликация.
- Подготовка новости и погодных сводок в отдельный личный предпросмотр.
- Расписание редакционных черновиков по времени Нячанга: доброе утро 06:30, прогноз 07:35, рубрики в течение дня, вечерний прогноз 19:30 и интерактив 22:30.
- Проверка существенных погодных изменений раз в час. Сообщение о пороговом изменении попадает редактору вне очереди, но остаётся черновиком.
- Генерация фона через OpenAI Images API, наложение кириллического заголовка через Pillow и повторное использование Telegram `file_id`.
- Лимит генерации: до 8 изображений в день, бюджетные пороги по умолчанию — $0.25 в день и $7 в месяц.
- Очередь и история в приватной таблице Supabase.

Если `OPENAI_API_KEY` отсутствует, бот оставляет материал в очереди и предлагает редактору прикрепить собственное изображение. Он не подставляет случайную фотографию из интернета.

## Запуск и настройки

См. [DEPLOYMENT.md](DEPLOYMENT.md). Секреты хранятся в GitHub Actions Secrets; пример локальных переменных находится в [.env.example](.env.example).

Нужны: Telegram bot token и числовой ID редактора, Supabase project, `OPENAI_API_KEY` для изображений, `WEATHERAPI_KEY` для погодных данных и, при использовании AI-проверки текста, `GEMINI_API_KEY`.

## Картинки и бюджет

Провайдер задаётся `IMAGE_PROVIDER` (сейчас реализован `openai`), модель — `OPENAI_IMAGE_MODEL`, качество — `OPENAI_IMAGE_QUALITY`. По умолчанию используется `gpt-image-2.5-flare` с низким качеством; фактическая цена зависит от числа image/text tokens, поэтому бот хранит измеренную стоимость и ограничивает количество запросов. Перед включением генерации проверьте оплату и доступ API в аккаунте OpenAI.

Стоимость одной иллюстрации нельзя гарантировать заранее: тариф рассчитывается по токенам. См. [официальное руководство OpenAI по генерации изображений](https://developers.openai.com/api/docs/guides/image-generation) и [текущие цены API](https://developers.openai.com/api/docs/pricing).
